# Production & Inventory Analytics

An end-to-end manufacturing analytics project focused on analyzing production performance, inventory levels, sales, capacity utilization, and key operational KPIs.

## 📌 Project Overview

This project analyzes manufacturing and inventory data to evaluate operational efficiency and business performance. The analysis combines Python-based data processing with Excel-based KPI calculations and dashboard reporting.

## 🎯 Objectives

- Analyze production planning vs actual production
- Evaluate production achievement and rejection rates
- Monitor inventory levels and stock-out instances
- Analyze sales revenue and units sold
- Measure production capacity utilization
- Calculate key financial and operational KPIs
- Build a management-friendly Excel dashboard

## 🛠️ Tools & Technologies

- Python
- CSV
- Microsoft Excel
- Excel Dashboard & KPI Analysis
- `artifact_tool`

## 📊 Key KPIs

The project calculates and visualizes:

- Total Revenue
- Production Cost
- Gross Profit
- Gross Margin %
- Planned Production
- Actual Production
- Production Achievement %
- Rejected Units
- Rejection Rate %
- Available Capacity
- Capacity Utilization %
- Average Inventory
- Units Sold
- Inventory Turnover
- Stock-out Instances
- Stock-out Rate %
